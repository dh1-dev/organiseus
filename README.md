# OrganiseUs Shopping Update

1. In Supabase, open **SQL Editor**, create a new query, paste `shopping-setup.sql`, and run it once.
2. In GitHub, upload and replace `index.html`, `service-worker.js`, `manifest.webmanifest`, `icon-192.png`, and `icon-512.png`.
3. Do not upload `shopping-setup.sql` to GitHub unless you want it stored there; it is only needed in Supabase.
4. Reopen OrganiseUs. If the old version remains, refresh once or close and reopen the installed app.
